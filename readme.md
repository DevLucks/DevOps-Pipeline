# DevOps Pipeline — CI/CD with GitHub Actions

A hands-on project demonstrating automated CI/CD workflows using GitHub Actions and Node.js.

---

## What This Covers

- Automated test execution on every push and pull request
- CI workflow configuration with GitHub Actions
- Node.js project setup with automated test and run scripts

---

## Tech Stack

- **Runtime:** Node.js
- **CI/CD:** GitHub Actions
- **Testing:** Custom Node.js test scripts

---

## Running Locally

```bash
# Install dependencies
npm install

# Run the app
npm run run

# Run tests
npm test
```

---

## CI/CD Workflow

Every push to this repository triggers a GitHub Actions workflow that:

1. Sets up the Node.js environment
2. Installs dependencies
3. Runs the automated test suite

This ensures code changes are validated automatically before merging.
